# Packaged audio checks

Run `python Tests/AudioMixer/check.py --runtime <directory-containing-DLLs>`
with a Python interpreter matching the build architecture. This loads the
packaged SDL DLLs and mixes audio into memory, without requiring an audio device.
Each format must produce non-silent PCM with streaming and predecoding enabled
in separate checks: WAV, MOD, FLAC, MP3 and Ogg Vorbis.

The WAV and minimal ProTracker MOD are generated by the test. The three small
files in `fixtures/` encode that generated 440 Hz WAV tone using FFmpeg's flac,
libmp3lame (32 kbit/s), and libvorbis (quality 1) encoders. They contain no game
assets. Keeping the encoded fixtures here avoids needing an encoder in CI.

To check detection of a missing MOD decoder, copy the staged DLLs to a temporary
directory, omit `libxmp.dll`, and run with `--expect-mod-failure`. The other
formats must still work. Use a separate process for each DLL directory.
